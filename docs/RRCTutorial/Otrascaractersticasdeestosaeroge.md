# Other characteristics of these wind turbines

The mechanism used to counteract the gust effect can also be used to change the "*Desired active power*": see Fig1 in [Control Terminal for Rotor Resistance Control](ControlTerminal.md).

![](<lib/Control Terminal en STOP.jpg>)

Another important characteristic is that the *power electronic control* used to change the rotor resistance is quite simple, and therefore, quite reliable and low cost.

A negative characteristic of this wind turbine type is that it dissipates more power: it is not so much a performance problem as a need for more powerful **cooling systems**.
