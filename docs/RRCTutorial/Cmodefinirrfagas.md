# How to define gusts

When a gust type is chosen, a submenu appears that allows choosing between "*Edit*" and "*Force*".

If "*Edit*" is chosen, the SynopticWindNacelle menu second option changes to "*Exit edition*" and the panel changes as presented in the following figure.

![](<lib/Edicion de ragafa.jpg>) Fig 1

In the left panel the wind value list ordered by increasing instants of the chosen gust type appears.

If "(new)" has been chosen then a synoptic appears that asks for the new gust type name, as in the following figure.

![](<lib/Anade rafaga.jpg>) Fig 2

Once the name has been entered and "OK" pressed, the following panel is presented, with the new gust type initial data.

![](<lib/rafaga inicial.jpg>) Fig 3

This situation is similar to the one indicated in figure 1.

## Gust profile shape edition

- **Add a new point.**

To add one more instance (time, wind) select any row in the left panel: press right button and a menu will appear with two options: "*Adding new point to the Profile*" and "*Delete point*".

If you choose "Adding new point to the Profile" a form will appear where you can enter the "time" and "wind" values, as in the following figure:

![](<lib/Anadiendo nuevo punto al perfil.jpg>)

If you press "OK", the right panel will change correspondingly. See the following figure.

![](<lib/Perfil despues de anadir un punto.jpg>)

- **Delete a profile point.**

Select the point with the mouse, right button "Delete point".

- **Change the values of a profile point.**

Select the point and delete it, add another new one.
