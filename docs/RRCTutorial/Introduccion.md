# Introduction

This document corresponds to the Simulator implemented on the **LdP v1r12** platform, using the "**RRCr12.conf**" configuration, and its associated objects.

April 2018 © Automated Computing Machinery SL (htpp://www.acm-sl.com).

It contains:

- A description of the wind turbine family that implements the Power Train control through the *rotor resistance variation of an induction generator*.

- The explanation of the fundamentals of this type of control.

- A description of the Simulator of this type of wind turbines.

- A set of "***Practical classes***", which are guided experiments that use the "Virtual Workbench" characteristics of the LdP platform, intended to:

- ○Graphically present the behavior of this type of wind turbines, in various working conditions.

- ○Confront the student with real situations that can occur in a physical installation.

This simulator relies on the concepts explained in the **Two-Speed and ActiveStall control Simulator**, with which it shares the functionalities related to yawing, brake system, etc. The explanation of the differences with the wind turbine type simulated here is described in [Reasons for the development of Wind Turbines with Rotor Resistance control](RazonesparaeldesarrollodelosAero.md).
