# Comparison of Power vs Wind Speed curves

!!! tip "🎯 Learning objectives"
    When completing this experiment you will be able to:

    - Understand the characteristic power curve of a wind turbine
    - Identify the differences in the energy conversion efficiency between technologies
    - Analyze the behavior in the speed zone below the nominal speed
    - Create normalized graphic representations to compare different wind turbines
    - Evaluate which technology makes better use of the wind in different conditions

### Introduction: The power curve

!!! info "📖 Fundamental concept: Power vs Wind curve"
    The power curve is a graphic representation that shows the relationship between the wind speed and the electrical power generated by a wind turbine.

    This curve is the "fingerprint" of each wind turbine and is fundamental to:

    - Estimate the annual energy production
    - Compare the performance of different technologies
    - Optimize the design according to the site conditions
    - Evaluate the project investment return

### Characteristics of the Power vs Wind curves

Make sure to read the concepts involved in the Power vs Wind Speed curves described in detail in the tutorial [here](../DFIGTutorial/Implicacionesdelcomportamientode.md).

!!! warning "⚡ Key difference between technologies"
    One of the main differences between the wind turbine families is the **effectiveness in the energy transfer when the wind speed is below the Nominal Wind Speed**.

    In this operation zone, the capacity to efficiently extract the wind energy determines to a large extent the wind turbine annual energy production.

### Characteristic zones of the power curve

!!! info "📊 Power curve regions"
    A typical power curve presents four characteristic zones:

    1. **Zone I - Below the cut-in:** Insufficient speed, wind turbine stopped (Power = 0)
    2. **Zone II - Between cut-in and nominal speed:** Increasing power, maximum energy use zone
    3. **Zone III - Between nominal speed and cut-out:** Constant power (Nominal Power)
    4. **Zone IV - Above the cut-out:** Wind turbine stopped for safety (Power = 0)

### Experiment objective

!!! tip "🔬 Experimental goal"
    The objective of this experiment is to **create comparative graphs** of the Power vs Wind Speed curves for the three main wind turbine families:

    - DSAS (Direct Stall Active Stall)
    - RRC (Rotor Resistance Control)
    - DFIG (Doubly Fed Induction Generator)
  
    The analysis will focus especially on **Zone II**, where the greatest performance differences are observed.

### Experiment methodology

!!! example "📋 Data preparation"
    ##### Step 1: Use the previous experiment simulators
    Take advantage of the simulators you already configured in the ["Comparison of cut-in in different wind turbine families"](ComparisonofcutinindifferentWind.md) experiment.
    ##### Step 2: Create the data structure
    Create a table with 4 columns:

    | Wind Speed (m/s) | DSAS Power (kW) | RRC Power (kW) | DFIG Power (kW) |
    | ----------------------------| --------------------| -------------------| --------------------|
    | 4                          | ...                | ...               | ...                |
    | 5                          | ...                | ...               | ...                |
    | ...                        | ...                | ...               | ...                |

    ##### Step 3: Data collection
    For each wind turbine:

    1. Set the wind speed (start from the cut-in up to speeds above the nominal)
    2. Wait for the wind turbine to reach stable operation
    3. Record the generated power in steady state
    4. Increase the wind speed in regular steps (recommended: 0.5 or 1 m/s)

### Data normalization: Per unit values (p.u.)

!!! warning "⚠️ Critical note on comparison"
    The three wind turbines have **different Nominal Power values**, which makes direct comparison difficult. Therefore, it is necessary to normalize the data using "per unit" (p.u.) values.

!!! info "📐 Per unit value calculation"
    To obtain the "per unit" (p.u.) values, divide each observed power value by the corresponding wind turbine Nominal Power:

    **Power (p.u.) = Measured Power (kW) / Nominal Power (kW)**
    Use the following Nominal Power values:

    - **DSAS:** 1300 kW
    - **RRC:** 660 kW
    - **DFIG:** 1500 kW
  

### Comparative graph creation

!!! example "📊 Graph generation"
    1. **Convert all the data to p.u. values** according to the previous formulas
    2. **Create a graph with:**
   
        - X axis: Wind Speed (m/s)
        - Y axis: Normalized power (p.u.)
    3. **Represent the three curves** in the same graph using different colors or line styles
    4. **Add a legend** identifying each curve (DSAS, RRC, DFIG)

### Results analysis

!!! tip "🔍 Questions for the analysis"
    Once the curves are obtained, analyze the following aspects:
    ##### 1. Comparison in Zone II (below nominal speed):
    - Which wind turbine has the steepest curve? What does this mean?
    - Which one reaches 50% of its nominal power sooner?
    - Which technology makes better use of low winds?
    ##### 2. Nominal wind speed:
    - At which speed does each wind turbine reach its nominal power?
    - Why can this speed be different between technologies?
    - What advantages does reaching the nominal power with lower winds have?
    ##### 3. Curve shape:
    - Which curve is smoother? What implications does this have?
    - Do you observe differences in the transition between zones?
    - How does the control system affect the curve shape?
    ##### 4. Conversion efficiency:
    - Which technology has greater efficiency in the low wind zone?
    - Which technology is more efficient in the medium wind zone?
    - How would you explain these differences from the technical point of view?

!!! info "💡 Physical interpretation"
    The differences observed in the curves are fundamentally due to:

    - **Control system:** Variable pitch vs fixed pitch vs variable speed control
    - **Generator type:** Squirrel cage, wound rotor, or doubly fed
    - **Speed range:** Fixed speed vs variable speed
    - **Regulation strategy:** Aerodynamic stall vs active control
  
    Each technology represents a different compromise between complexity, cost and performance.

### Practical application

!!! warning "🌍 Relevance in real projects"
    The knowledge of these curves is essential for:

    - **Wind turbine selection:** Choosing the most appropriate technology according to the site wind profile
    - **Production estimation:** Calculating the estimated annual energy combining the power curve with the statistical wind distribution
    - **Economic analysis:** Evaluating the profitability considering the investment vs expected production
    - **Wind farm optimization:** Deciding the optimal technology mix in a wind farm

### Conclusions and reflections

!!! tip "📝 Summary of key concepts"
    - The power curves characterize the performance of each wind turbine
    - Normalization (p.u. values) allows comparing wind turbines of different sizes
    - The zone below the nominal speed is critical for the annual energy production
    - Each technology has advantages in different wind speed ranges
    - The optimal selection depends on the specific site characteristics
