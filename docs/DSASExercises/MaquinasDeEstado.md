# Tracking the Controller evolutions (State Machines) in various conditions

!!! tip "🎯 State machines"
    ***Objective:*** Understand the operation of a state machine and how it describes the wind turbine operational behavior.
    ***What to observe:*** Main states, transitions, entry/exit conditions and events (alarms, permissions, setpoints).
    ***What to note:*** For each transition: origin state, destination state and the condition that triggers it.
    💡 draw a mini-diagram with 4–6 key states and their transition arrows.

In this practice the objective is to become familiar with the State machine evolutions during various operations:

- [Start-up](MEstadoCutin.md) (cutin)

- [Generator disconnection](MEstadoCutout.md) (cutout)

- [Generator connection type change](MEstadoCambio1000a1500.md).
