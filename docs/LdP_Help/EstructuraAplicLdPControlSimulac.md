# Simulation Control

LdP has a **Control** synoptic that allows the following functionalities:

- The **execution** of a configuration file (*Run, Stop, Continue*).

- The **graphic presentation control** on screen of the configuration synoptics.

- The **editing of the values associated with Parameters**.

- The **editing of Connections**.

- The **access** to the set of **Tutorials** associated with the running configuration.
