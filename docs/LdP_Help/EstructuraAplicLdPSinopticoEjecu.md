# Execution Control Synoptic

This synoptic is common to all LdP applications:

![](<lib/Sinoptico Ejecutando en espanol.jpg>)

The following table shows a description of the functions associated with each of these buttons.

| ![](<lib/Boton salir.jpg>) | For exiting the program.<p> The exit is not immediate, and must be confirmed. See next figure.</p> ![](<lib/Confirmacion_salida.jpg>)  |
|---|---|
| ![](<lib/Boton Ejecutar.jpg>) <p>![](<lib/Boton Parar.jpg>) </p> ![](<lib/Boton Continuar.jpg>) | These buttons controls the  *actual execution of the Simulation*. <p>**Run** initiates the Simulation. </p> <p> Pressing the When you press the "**Stop**" button the temporal evolution of the Simulator signals is suspended. </p> <p> Pressing the "Continue" button resumes the execution.</p>  |
| ![](<lib/Boton sinopticos.png>) | This button is used to control of the visibility of all the synoptics: pressing it presents dropdown list of all of them: the first three, are the common *LdP ones* ("**Signals and Connections**", "**Parameters**" and "**Recorders**"). The remaining items corresponds to each one of the synoptics specific for the Simulator being executed. Checking/unchecking the associated checkbox brings up the corresponding synoptic to the surface of the screen. <p> ![](<lib/Listado sinopticos retocado.png>) </p> <p>The synoptic visibility control can also be done through the icons installed in the Windows toolbar. Next figure shows part of the bottom toolbar, with the icon to access all the opened synoptics. </p> ![](<lib/Acceso_a_sinopticos_por_toolbar.jpg>)  |
| ![](<lib/Boton tutoriales.jpg>) | This button allows you to access the tutorials associated with the Simulator that is running. |
| ![](<lib/Boton mensajes.jpg>) | This button expands the synoptic to include a message area that the application can send to the user. It is mainly used for debugging configuration files. |
| ![](<lib/Boton informacion versiones.jpg>) | This button allows access to information about the LdP version and the Simulator that is running. It also allows access to information about the product usage license. See [Version and license information.](InformacionVersionylicencia.md) |
