# Display of recorded values

The record files (*datalogging*) are stored in the "*C:\\WFS\_Datalog\\name\_of\_the\_simulator*\\" directory and their name reflects the instant the simulation session began.

The files created with SQlite can be managed by a large number of applications, including many that are "open source". For example the "*SQLite Manager*" plug-in of the *Firefox* browser allows opening and editing these files. See the following figure.

![](<lib/Datalogger SQLite Manager.jpg>)
