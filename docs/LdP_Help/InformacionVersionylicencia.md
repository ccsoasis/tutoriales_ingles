# Version and license information

The "*Application Information*" button of the execution control synoptic presents the following synoptic:

![](<lib/InfoLicencia y versiones.png>)

It displays the following information:

- The LdP version that is running.

- The application that is running ("DFIGv10Spanish.conf" in the example shown).

- The list of the components (DLLs) used in the application with their versions.

Access to information about this application usage license can be obtained through the "*LicenseInfo*" menu option, which presents the following synoptic.

![](<lib/Licencia remarcada.png>)

The "License ID" value is the code you should use for any communication with our support department (support@acm-sl.com).
