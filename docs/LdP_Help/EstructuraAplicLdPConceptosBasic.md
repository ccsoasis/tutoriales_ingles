# Basic concepts

The LdP structure is designed to facilitate the Simulators design: a basic concept is to use a very intuitive and accepted paradigm: an electrical cabinet or electronic device. These equipments have independent and interconnected "*components*" (electrical or electronic). The *connections* between these components are made by means of the electrical wire simile that connect "*output signals*" with "*input signals*". An output signal can be connected to one or more input signals, but not to another output signal.

As a result, these connections can be represented with an electrical diagram.

LdP has "tools" for observing these connections and changing them, so that their functionalities match those of a "workbench or laboratory," where power supplies, voltmeters, ammeters, oscilloscopes, etc. are available.

In addition, LdP provides a database record of all changes that occur in the Simulator signals, with a resolution of 1 millisecond.
