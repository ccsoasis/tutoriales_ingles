# Exporting data to Excel

The SQLiteAdministrator desktop application ([http://sqliteadmin.orbmu2k.de](http://sqliteadmin.orbmu2k.de)/) has an option to export the SQlite file data to Excel.

![](<lib/SQlite administrator espanol 1.jpg>)

The Firefox "SQLite Manager" plugin also allows you to export the results of a query to a CSV (Comma Separated Values) file.

![](<lib/SQLite manager firefox para csv.jpg>)

These files can be imported to Excel books. The latest Excel versions include a format that well collects the date format with millisecond resolution. See the following figure to observe the translation of the "Date" column (the "A") to the translated one with the indicated form (column "B") that is being represented with the cell format "*dd/mm/yyyy h:mm:ss,000*".

![](<lib/Datalogger datos en Excel.jpg>)
