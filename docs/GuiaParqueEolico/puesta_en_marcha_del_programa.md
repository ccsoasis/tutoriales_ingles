# Program Start-up

When the Wind Farm Simulator program is executed, two windows appear (which we call "synoptics" in this context):

- A synoptic with title "URL", which presents on screen the Tutorial associated with this Simulator in a separate window. This synoptic appears on top of all the others. You can move it to any part of the screen, or *minimize* it ("**-**" frame option), or *remove* it ("**x**" frame option).

    - If you minimize it you can find it on the screen in two ways:

        - Either by pressing the "**Alt**" keys and then "**Tab**" simultaneously: a panel will appear with images corresponding to each window that exists at that moment; you will be able to move between them by repeatedly pressing the "Tab" key.

        - Or by finding the icon   in the "**Toolbar**": when pressing it a set of icons will appear corresponding to the windows (synoptics) of the current application ("Simulator").

    - If you remove it, you can present it again by going to the "**Running WFSSCADA**" synoptic, pressing the "Tutorials" option and choosing the "Wind\_Farm\_Simulator\_SCADA" option in the drop-down menu that appears.

- Another synoptic with title "**Running WFSSCADA**"

    - With this synoptic options you can:

        - "**Exit**" the Simulator,

        - "**Run**" the simulation,

        - access specific "**Synoptics**",

        - present the "**Tutorials**"

        - access information about the Simulator

    - A complete description is described in this [tutorial](../WFSSCADA/ComponentesdelSimulador.md).
