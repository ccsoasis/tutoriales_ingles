# Production Evolution of each Wind Turbine over time

The SCADA systems allow visualizing the evolution of certain Wind Farm variables. In the simulator this can be carried out using **recorders**. You can see how it is carried out in the **[tutorial](../WFSSCADA/SimulacindePuestaenNodisponibled.md)**.

You can create as many recorders as you **[want](../WFSSCADA/PowerpergroupTotalproducedPowera.md)**.

The recorders have the "**[active copy](../WFSSCADA/Grficosdeevolucindeseales.md)**" functionality, with which it is possible to make time measurements (relative to a certain instant), and image copies of their content can also be obtained, which pass to the clipboard and can be incorporated into any document (text, presentations, etc.) See the **[tutorial](../LdP_Help/Introduccion.md)**.
