# Simulation Execution

The Simulation program execution does not automatically launch the Wind Farm Simulation. This is due to two reasons:

- Some *parameters* of the internal simulators may want to be *changed* (see the "[Parameters](../WFSSCADA/Parameters.md)" synoptic, in the "**Synoptics**" menu option)

- The execution may want to be *temporarily stopped*, to resume it later, after making changes.

**To launch the Simulation** you must press the second button from the left of the "**Running WFSSCADA**" synoptic, with initial title "**Run**", which changes to "**Stop**" after being pressed, and, if pressed again it changes to "**Continue**".
