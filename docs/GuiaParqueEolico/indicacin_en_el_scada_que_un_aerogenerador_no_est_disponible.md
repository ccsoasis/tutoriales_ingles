# SCADA indication that a wind turbine is not available

In the Simulator it is indicated that a certain **wind turbine is not available** in several parts of the main synoptic.

- In the "**State**" column of the SCADA grid: "Not available".

- In the "**Est.Comm**" column ("*Communications state*"), through a "red" indicator.

- In the upper part of the synoptic, where an icon per wind turbine is presented. If it is in red it means not available.
