# Aerodynamic coefficient: Cp function

## Aerodynamic coefficient Panel

The purpose of the diagram in this panel is the presentation of the instantaneous aerodynamic coefficient (Cp) value, which depends on the blade tip speed and the incident wind (TSR) and on the Pitch angle. See [Description of the Cp function (aerodynamic coefficient)](DescripcindelafuncinCpcoeficient.md).

The Cp value is indicated with the icon ![](<lib/Icono Cp.jpg>); the abscissa axis corresponds to the TSR and the red curves correspond to the Pitch value labeled on them. This function is complex: a view has been chosen that allows following the evolution of the Cp as the wind turbine working conditions change. To further aid its understanding, a set of 3D views has been added that are accessible through the selector indicated as "3D views".
