# List of Incidence messages

| Text in English | Translation |
|---|---|
| Manual STOP | The generator is not in Production. |
| External STOP | An external order to leave production has been received |
| Emergency STOP | Emergency stop order received |
| Grid phase failure | Voltage failure on the grid |
| Undervoltage | Tension fell below the minimum level for more than 2 seconds |
| Overvoltage | The voltage in one of the phases of the grid has exceeded the maximum permitted value for 2 seconds. |
| Generator superheated | The temperature of the electric generator has exceeded the maximum value. |
| GearBox heated | Excessive temperature in the multiplier. |
| Error in temp measurements | Error to measure some temperature |
| RotorBearing superheated | Excessive Rotor bearing temperature |
| Ambient Temp too high to operate | The room temperature is too high to operate |
| Vibration sensor | The Tower vibration sensor has been activated |
| Rotor or Gen rpms sensors disconnected | Error in the measurements of the Rotor or Generator axis revolutions |
| Pump starts too often | The hydraulic brake circuit pump has been put in place too often |
| Pumping time too long | The hydraulic brake circuit pump has been connected for an excessive time |
| Yawing time too long | The orientation engines have been working for too long. |
| Over speed VCU | Superspeed on the axis of the Generator |
| Over speed HCU | Overflow on the Rotor axis (blades) |
| Brake not released | The brakes have not been released |
| Cables max twisting | The maximum turn of power cables has been reached |
| Wind &gt; WindMaxForOperation for more than 100 s | The wind has exceeded the value of the parameter "Maximum wind for continuous operation," for more than 100 s. |
| Wind &gt; WindMaxForTemporalOperation for more than 5 s | The wind has exceeded the value of the parameter "Maximum operating time wind" for more than 5 s. |
| Wind &gt; WindAbsolutMax for more that 1 s | The wind has exceeded the value of the parameter "Maximum absolute wind" by more than 1 s. |
| Pitch difference between command and actual too high | The difference between Pitch's required value and the real value in the blades has an excessive difference |
