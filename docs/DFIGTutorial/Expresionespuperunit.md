# pu expressions (per unit)

In the panels of this section some measurements are presented in "pu's" (*per unit*). The idea is to present the real value of the variable but referred to a value that is taken as a presentation unit.

For example, in [Mechanical and electrical powers vs Rotor speed](DFIGWTTCPanelPotenciaVSrpms.md), the Powers are indicated in pu's, taking as the unit value the one indicated in the same panel (1,500 kW). Thus the pu value of 1,500 kW is 1.0. 750 kW is 0.5 pu's.

This concept is very useful for the comparative representation of values of several variables on the same graph, even though their ranges are very different.
