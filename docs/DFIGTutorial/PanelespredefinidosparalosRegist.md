# Predefined panels for the Recorders

This Simulator includes a set of predefined Panels, designed specifically to observe the evolution of different sets of signals, each for specific experiments.

These designs affect:

- The set of signals presented in the same Record.  
Each Record in a Panel can present more than one signal, which facilitates the comparison of their evolution.

- The color associated with each signal.

- The value range of each Record.  
The vertical axis (ordinates) can have a value range that does not correspond to the signal value range. This allows defining zoom views.

- The order of the Records in the Panel.

- The height of each Record.

- The background color of the Panel.
