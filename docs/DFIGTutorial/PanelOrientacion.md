# Guidance

![](<lib/StripRecorder Nacelle orientation.png>)

This graph allows you to view the variables related to Nacelle orientation.

The first recorder presents the wind direction (between 0º and 360º) and the Nacelle orientation: this value takes into account the number of turns that power cables.

The above graph has been obtained by slowly increasing the wind direction (using the "Arrow Up" key). It can be seen that the direction of the Nacelle "follows" the evolution of the direction of the wind because the corresponding engine is being launched (in blue). This evolution changes when you reach the maximum number of cable turns (2.5 in this case): from that moment on you start the roll of the cable turns (red engine), which ends when the Nacelle orientation coincides again with the wind direction.
