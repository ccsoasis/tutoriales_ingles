# Internal view of the nacelle

![](<lib/Vista interna gondola sola.jpg>)

This view presents several key components of the wind turbine. Starting from the left:

1. The Hub, where the blades are not shown, replaced by indicators of their angle (Pitch) (in red).

2. The main support bearing of the elements attached to the Hub.

3. The gearbox.

4. The brake disc. In some wind turbines, this disc is located on the gearbox low-speed shaft.

5. The hydraulic brake control system. See [Brake mechanism](DFIGWTGondolaFrenos.md).

6. The coupling of the Generator rotor shaft with the gearbox high-speed shaft. This element allows some tolerance in the misalignment between these two shafts.

On the other hand, in many DFIG wind turbines, the Back-to-Back converters are located in an electrical cabinet situated in the nacelle, near the electric Generator. This case is not shown in this synoptic to facilitate the real-time visualization of the other components. A description of this cabinet is found in [Electrical cabinet](DFIGArmarioElectrico.md).

**Commands for the temperatures of key elements**

![](<lib/Gondola con temperaturas.jpg>)

Through the menu bar of this synoptic, the presentation of graphic commands can be controlled, with which it is possible to change the temperatures of certain key elements.
