# Power Train operational curves

## Power Train operational curves

This synoptic presents, in four panels:

- Graphs corresponding to key wind turbine parameters.

- Curves corresponding to the values in stable operation.

- Real-time representation, drawn on the previous graphs, of the instantaneous values of key variables.

The panels illustrate the operating principles described in [Implications for the Power Train](ImplicacionesparaelTrendePotenci.md).

![](<lib/Curvas oper produccion espanol.jpg>)

*Note: the curve values and in general the involved variables depend on the air density. This value is associated with the "Ambient"-->"Air density" Parameter and can be changed at any time. The value used for the shown graphs is 1.225 g/m3.*
