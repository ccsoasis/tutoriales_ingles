# Vibrations in the Tower

The SynopticDriveTrain contains the vibration sensor simulator. This sensor is located in the tower and monitors that there are periodical movements whose amplitude exceeds a certain level.

![](<lib/Vibraciones en la torre espanol.jpg>)

The implementing simulator leaves the user to generate the signal that would occur in case these vibrations occur. When the Controller is activated, start a type 3 emergency stop.

It's button is always in "Forzar" mode, so your box is in red.
