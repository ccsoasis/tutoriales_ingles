# Signal evolution graphs

The "Synoptics" -&gt; "Recorders" option **creates a "Recorders" instance each time it is pressed**. A synoptic like the one in the following figure will appear.

![](<lib/Registradores sin asignar.png>)

When pressing "***Predefined panels***" the following options menu will appear.

![](<lib/Registradores SCADA - opciones.png>)

If you choose one of them, for example the second and wait a sufficient time, you will obtain a graph like the following.

![](<lib/Registradores SCADA - ejemplo 1.png>)

The "Copy" option of these "Recorders" synoptics allows obtaining an "***active copy***". See "[Copy](Grficosdeevolucindeseales.md)"
