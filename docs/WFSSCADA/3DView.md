# 3D View

The simulator includes an interactive 3D view. The control of this synoptic, which is presented separately, is in the SCADA synoptic center, labeled with "**Farm 3D View**"

![](<lib/Sinoptico SCADA vista 3D.png>)

The label contains the wind turbine name, its Nacelle orientation, and the blade rpms.

The point of view can be changed by pressing the left button while dragging the mouse.

To change the view to a certain wind turbine it is selected with "*double click*" in the SCADA view.
