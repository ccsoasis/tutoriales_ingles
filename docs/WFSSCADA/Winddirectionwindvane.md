# Wind direction: wind vane

This sensor gives the wind direction. Its output can be:

a) in the form of an analog signal (typically, a voltage).

b) or as the output of an absolute digital encoder.

![](<lib/Veleta de Campbell.png>)

The wind vane reference must be calibrated to geographic North.

In the case of giving analog output, it is also necessary to calibrate the output value for 360º with respect to the reference (North).
