# Predictive Maintenance

This maintenance is more a work philosophy that encompasses several tasks. Generally it is supported by special instrumentation that is usually incorporated to the wind turbines and that allows the collection of additional data on various elements. Singularly the gearbox, the rotor bearings and the generator.

The collected data are processed to detect signal evolution patterns that indicate changes in the internal behavior of these elements. There can be large savings in the farm exploitation if a possible breakage of these elements is detected with enough anticipation.

This potential saving can come from several sources:

- a better planning of auxiliary elements not existing in the farm, such as large cranes. For example grouping the works in several wind turbines to avoid the cost of moving these cranes.

- a better planning of the material that must be in stock. Generally, certain elements, such as gearboxes, can have very long delivery periods (months), which forces a breakage forecast to stock a sufficient number of them, in order not to incur serious losses due to lost profit.

- reduction of the fault magnitude: an early detection of a defect for example in a gear tooth, can be solved with some technical requirements and suppliers (e.g., local) with a much lower cost than if the fault is not detected (and therefore not repaired), which can entail a much deeper fault, that forces changing the whole gearbox.
