# Wind measurement: anemometer

This instrument type is placed in the Nacelle rear part (see [What is a Wind Turbine?](WhatisaWindTurbine.md)) and its operation is shown in the following video.

![](<lib/Anemometerswf.gif>)

The output of this device is usually a digital signal whose *frequency depends on the incident wind speed*. The relationship between this frequency and the wind value is quite linear, although it requires some approximation, as can be appreciated in the following graph.

![](<lib/Curva anemometro espaol.png>)
