# Simulator Components

This simulator contains a main synoptic, shown in the following figure.

![](<lib/Simulador SCADA espaol.png>) Fig 1

In it sets of graphic indicators and interactive buttons are included that present different data to the user, and allow interacting with the simulator. These graphic sets are described in the sections that follow.

Additionally, the simulator, being an application executed on **LdP** (See the "[*Introduction to LdP*](../LdP_Help/Introduccion.md)" tutorial), includes the [execution control synoptic](ComponentesdelSimulador.md), as shown in the following figure.

[![](<lib/Sinoptico control SCADA.png>)](ComponentesdelSimulador.md) Fig 2.

In addition, this simulator configuration includes a predefined set of "[Recorders](PowerpergroupTotalproducedPowera.md)" ("*Synoptics*" -&gt; "*Recorders*") designed to facilitate the observation of different wind farm variables in the simulator.
