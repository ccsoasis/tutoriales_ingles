# Obtaining active copies

The "Recorders" synoptics have the "**Copy**" option that allows creating a synoptic that is a copy of the graphic content existing at that moment in the Recorder. It also has two important functionalities:

- It allows the **measurement of time intervals** between a reference instant (definable by the user).

- It allows **passing a copy of the graphic content to the clipboard**, so that it can be used in office applications.
