# Wind turbine state change

To carry out this practice make sure the "***Automatic control***" mechanism is not active.

- 1.Choose a wind turbine that is in production.

- 2.Press on its "*Start/Stop*" column: observe that it passes to "<mark>Stop</mark>" and that the Total Power decreases with the power value that this wind turbine was producing.

- 3.Choose a wind turbine that is in "<mark>Stop</mark>".

- 4.Press on its "Start/Stop" column: observe that it passes to "<mark>Production</mark>" and that the Total Power increases with the power value of this wind turbine.
