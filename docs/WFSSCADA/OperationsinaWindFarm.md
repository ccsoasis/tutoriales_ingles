# Operations in a Wind Farm

In a Wind Farm the production is determined by a set of factors:

- Wind availability and the meteorological conditions

- State of each one of the Wind Turbines.

- Planned Client demand.

- Maintenance Planning.

In this simulator there are the user interfaces to be able to change the values corresponding to these concepts.

These factors can be grouped into two large groups:

- [Production Control](Productioncontrol.md).

- [Maintenance Management](ControldelaProduccin.md).
