# Wind speed change

The text box labeled "Wind (m/s)" allows **changing the wind speed**.

The modification can be done by entering this text box (click with the left mouse button) and typing the desired value. You will check that when the value is changed, the background becomes "<mark>yellow</mark>": this indicates that the value read at that moment and the real one being used are not the same. When you press "return" on the keyboard, the entered value will become the current one, and this text box background will become white again.

**If you regret trying to change the value** when you have already started this operation, simply press the "Esc" key on the keyboard (top left).

The **recommended wind speed change method** is using the arrow keys (up, down) or the paging ones (PgUp, PgDn). With the arrows the value changes in 0.1 m/s steps, with the paging ones the step is 1 m/s.
