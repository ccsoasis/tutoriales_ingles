# Synoptics used in this simulator

The synoptics constitute the Simulator user interface. They contain a set of graphic elements (*widgets*) where the *values of certain simulator variables* are presented. It has the most adequate shape (linear, circular, etc.) for the variable type and its value range.  
Some of these graphic elements also allow controlling the value associated with the variable.

A general description of the functionality of these graphic elements is found in the LdP platform help file ([LdP_Help.html?Introduccion.html](../LdP_Help/Introduccion.md)).

In relation to the synoptics used in LdP there are two types:

- 1.The ones that allow the simulation execution of a configuration, the visualization of the subprocess parameters defined in that configuration, run-time edition of the connectivity between the subprocesses, and the presentation of graphic recorders: they are known in LdP as "*Common Synoptics*".

- 2.The synoptics that are defined in the configuration being executed.
