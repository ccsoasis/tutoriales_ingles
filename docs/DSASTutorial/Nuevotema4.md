# Control Terminal

It is important to always keep in mind that the wind turbine is an **Electrical Production Plant**, designed **to operate autonomously**. That is, a plant that does not need any human presence to operate. This implies that it must have a *Control system* properly programmed so that it takes into account all the incidents that may occur to it, such as

- *external phenomena*, such as hurricane winds, lightning strikes, excessive or very low temperatures,

- *incidents generated by the Electrical Grid* to which it is connected (faults in some phase, line voltages out of limits, etc.),

- *internal incidents*, such as hydraulic component breakage, sensor decalibration or breakage, excessive vibrations, bearing problems, generator temperature rise, etc.

The Controller has programming that allows the timely detection of all these incidents, as well as the procedures to respond to them. This implies that the way to interact with a wind turbine is by communicating with its Controller, which is done through specific **Data Terminals**.
