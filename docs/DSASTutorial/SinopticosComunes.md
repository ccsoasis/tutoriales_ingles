# Common LdP platform synoptics

For a detailed description of the capabilities and base synoptics of the LdP platform on which this simulator runs you can consult the [Introduction to LdP](../LdP_Help/Introduccion.md) tutorial.

The common synoptics are accessible in the "Running Simulator xx" synoptic, third button from the left ("Synoptics") and refer to:

- the Signals defined in the different Simulator subsystems, and their connections ("[Signals and Connections](Indicadoresycomponentesgrficosso.md)"),

- the defined parameters associated with the different algorithms used, both for the simulation of the physical elements, and those used in the Controller ("[Parameters](Cambiodelasconexionesdelaconfigu.md)"),

- the creation of "[Recorders](Comopresentarenprimerplanoundete.md)" to visualize the signal evolution.
