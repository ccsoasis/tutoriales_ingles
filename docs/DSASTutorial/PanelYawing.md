# Panel 'Hydraulic brake circuit'

The following figure shows the panel called 'Hydraulic brake circuit', which contains 5 channels.

![](<lib/RegistradorCircuitoHidraulico.jpg>)

- 1.In the first 'channel' the **hydraulic circuit pressure** signal is presented, in % over the nominal.

- 2.In the second 'channel' the **pump activation** signal is presented.

- 3.In the third 'channel' the **pressure switch** output signal is presented.

- 4.In the fourth 'channel' two signals are presented:

- 1.The **'Hard brake' activation** signal.

- 2.The **'Normal brake' activation** signal.

- 5.In the fifth 'channel' the **'Brake released'** signal is presented.
