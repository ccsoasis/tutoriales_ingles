# Aerodynamic coefficient

In the following graphs the shape of the **aerodynamic coefficient** (**Cp**) function is shown in 3D views, using as independent variables the blade angle (**pitch**) and the relationship between the equivalent wind speed at the blade edge due to its rotation, and the incident wind (the real one), which is known as **TSR** (*Tip Speed Ratio*).

It can be seen that it is a complex function. Another important conclusion is that it has a maximum value at a point, for a certain Pitch and TSR, which depends...

An important conclusion of the analysis of this function is that it is observed that there is a point that has the highest Cp. Said point is found at Pitch values very close to 0º and for a certain TSR value. This implies that obtaining the maximum power corresponds to Pitch close to 0º.

Another conclusion is that the **maximum Cp** is obtained (in the figure case) with a TSR value around 6 (typically between 6 and 9).
