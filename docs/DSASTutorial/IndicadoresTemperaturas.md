# Temperatures

![](<lib/SynopticDriveTrain vista interna con temperat.png>)

In the [Interior nacelle view](VistaInternaGondola.md) a set of graphic indicators can be presented or hidden that allow modifying the **temperature** of each of the following elements:

- Of the **electric generator**.

- Of the **gearbox**.

- Of the **rotor bearing**.

- Of the **environment**.

- Of the **brake disc**.
