# Controller state machine indications

This synoptic presents the current data of the Controller **state machines**.

The state machines are a description paradigm of the Controller part that coordinates the different control algorithms of each of the subsystems (**Operations**), and also takes care of supervising the machine safety (***Security***).

The state machines receive specific "*events*" that can potentially make their "state" change. In the central part of this synoptic the last event received and the current state of each of the two state machines are shown.

In the "**Messages**" tab the sequence of events generated is presented, with their date.
