# Configuration connection change

It is possible to change the existing connections in the simulator configuration, without having to stop the simulation execution: this functionality opens many possibilities for its use as a test bench.

To do so it is necessary to access the "*Running Two-Speed Wind Turbine Simulator*" synoptic, "*Synoptics*" menu, the "*Signals and Connections*" option. A form like the one in the following figure will be presented.

![](<lib/Senales y conexiones - conexiones internas.png>)

Each row corresponds to a connection between an "*Output*" signal and an "*Input*" one. If you select a row you can use the "*Del*" key to delete that connection.

For a complete description of this functionality see the "Introduction to LdP" tutorial.
