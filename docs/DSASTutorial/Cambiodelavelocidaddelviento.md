# Wind direction change

To change the wind direction, you must use the text box labeled "Wind direction".

Click the text box (left-button click) and type the desired value. When the value in the text box differs from the *internal* value of the associated signal, the text box background becomes "<mark>yellow</mark>". When you press "Return" on the keyboard, the entered value becomes the new value of the associated signal, and the text box background becomes white again.

**To return to the previous value, press the "Esc" key on the keyboard (the key at the top left of the keyboard) before pressing "return".
