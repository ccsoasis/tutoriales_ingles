# Controller

A Wind Turbine is an *Electricity Production Plant* designed to operate **stand-alone**, without requiring external support from any external system or any person inside it. This approach imposes very heavy demands on:

- 1.**The reliability of the algorithms that control each of its subsystems**, and must be field-tested.

- 2.**The real-time reactions to key incoming signals**

Typical implementations are on:

- 1.**Industrial computers**, with *real-time operating systems*. These are high-reliability versions of common computers, where the response time to key operations is known, unlike standard operating systems, where response to a given task depends on its existing *load* (the set of additional programs running simultaneously).

- 2.**Programmable Logic Controllers** (PLCs), a type of industrial controller, focused on the responses to input and output signals, to facilitate its programming. This is done using specialized programming languages.
