# Automatic

The **Automatic** mode is the normal wind turbine operating mode. In this mode the Controller takes control of the different wind turbine elements with the objective of keeping it in production, provided the adequate conditions are met.

In this mode the Controller stays attentive to commands that can come from the Operator, through their Control Terminal, or from the Control Center, through a data connection.
