# How to present a given synoptic in the foreground

The specific synoptics of this configuration can be presented and hidden using the boxes associated with their list, which appears by pressing the "Synoptics" menu button in the execution control synoptic. See the following figure.

![](<lib/Sinopticos-espanol.jpg>)

Their on-screen presence can also be controlled using the specific icons that appear in the "**Toolbar**". See the following figure.  
![](<lib/Iconos-en-barra-herramientas.jpg>)

Putting the mouse cursor over the "ACM" icons a text with the associated synoptic name will be presented.

Clicking with the left mouse button will present or hide the corresponding synoptic.
