# Parameter value change

To change a parameter value, open the "***Parameters***" synoptic: in the "Running Simulator xxx" synoptic, press the third button ("Synoptics"); a list will appear. You must select "Parameters".

Clicking the column headers reorders the table content.

![](<lib/parametro-leakage-normal.jpg>)

Fig 1.

To change the value of a parameter, click the box in the "Value" column for that parameter. For example, to change the value of "NacelleBrake.LeakageBrakeHydrCircuit," click on the box with "0.01". The background color will change to blue.

Click a second time so the background changes to yellow.

Type the desired value (within the range indicated by the "Max" and "Min" columns). Then press Enter or move the mouse outside the box.
