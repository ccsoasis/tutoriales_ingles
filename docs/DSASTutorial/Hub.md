# Power Train

The Hub representation includes:

- the blade rotation around the Hub axis, according to the current value of the Rotor revolutions

- the blade and generator shaft revolution indicators

- the excess revolution indicators in the blade shaft and in the generator shaft.

![](<lib/Indicadores Tren potencia.jpg>)

These graphic indicators can be put in "*command*" mode (*'F6'*), which allows creating fault simulations without having to change the simulator configuration. See [Indicator connections](TrendePotencia.md).
