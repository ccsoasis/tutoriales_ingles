# Views

This synoptic contains the graphic elements where the different nacelle components are presented. It has two menu options:

- one to control the *'Views'*, which are two:

- 1.['3D exterior view'](Vista3D.md)

- 2.['Internal nacelle view'](VistaInternaGondola.md)

- another (*'Instrumentation View'*) to present the indicators of the most significant variables.

In the *'Internal nacelle view'* a third option (*'Temperatures'*) appears that presents/removes the temperature indicators of several elements.
